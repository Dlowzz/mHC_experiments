# 数据解释：流分析记录 (mHC vs mHC-Group-LoRA)

本文件解释 `eval/analysis_out/` 下两份论文分析记录的**数据结构与字段含义**，方便他人（或直接贴给 GPT）理解。

## 文件
- `mhc.analysis.pt` —— 纯 mHC（`hyper_conn_type=mhc`）
- `mhc_group_lora_midnorm.analysis.pt` —— mHC-Group-LoRA-midnorm

均由 `eval/record_analysis.py` 生成，`torch.save` 的 pickle（**二进制，不能直接粘贴**，需 `torch.load` 后查看）。

## 采集协议（provenance）
- 数据：openwebtext `train.bin` 的**前 64 条、每条 1024 token**（非重叠、从头取，两模型完全相同的数据与顺序）。
- 模型：加载训练好的 L 档 ckpt（`iter 29500`），`model.eval()`，**全程 float32**、无 autocast。
- 计算：模型自身的 mean 交叉熵 loss，做**真实前向 + 反向**；保存**未缩放梯度**（无 grad clip、无 optimizer step）。所有保存量转 float32。

## 顶层结构
```python
d = torch.load("mhc_group_lora_midnorm.analysis.pt", weights_only=False)
d["meta"]                       # 元信息（见下）
d["layers"]["L0.attn"]          # 第0层 attn site
d["layers"]["L0.attn"]["routing"]["Hpre_raw"]   # 具体张量
```
- `layers` 的键：`"L{层号}.{attn|mlp}"`，共 `n_layers × 2 = 48` 个条目。
- 每个条目按类别组织：`routing / gradient / stream_state / lora`，类别下是「指标名 → 张量」。

## meta 字段
- `model_name, hyper_conn_type`：模型标识
- `n_streams=4`（残差流数 n）、`n_layers=24`、`sites=[attn,mlp]`、`dtype=float32`
- `is_group`：是否 group-LoRA
- group 专有：`n_groups=4`（Q）、`group_dim=256`、`lora_lambda=1.0`、`lora_rank=8`
- `dims`：每个张量的**轴含义**（下表即来源于此）

## 张量维度与含义（全量、token 级、未平均）
所有张量前两维恒为 `[sequence=64, token=1024, ...]`。n=stream=4，Q=group=4（mHC 时 Q=1）。

| 类别 | 指标 | 形状 | 含义 |
|---|---|---|---|
| routing | `Hpre_raw` | [S,T,Q,n] | 读门（sigmoid）；mHC Q=1，group 每组一套 |
| routing | `Hres_raw` | [S,T,n,n] | 残差混合矩阵 [src,dst]，**dst 轴(-1)精确和为1** |
| routing | `beta` | [S,T,n] | 写门 H_post ∈ (0,2)，每流一个标量 |
| routing | `read_contrib_norm` | [S,T,Q,n] | ‖Hpre[q,s]·x[s,q]‖，各组对各流的实际读取贡献 |
| gradient | `stream_grad_norm` | [S,T,n] | ‖dL/dx_s‖，每流残差输入的梯度范数 |
| gradient | `beta_grad` | [S,T,n] | dL/dβ_s（带符号） |
| gradient | `read_grad_norm` | [S,T,Q,n] | ‖Hpre[q,s]·dL/du_q‖，读取边的梯度重要性 |
| stream_state | `rms_before_read` | [S,T,n] | 进入 site 前每流 RMS |
| stream_state | `rms_after_hres` | [S,T,n] | Hres 混合后每流 RMS |
| stream_state | `rms_after_write` | [S,T,n] | 写回后每流 RMS |
| stream_state | `read_stream_cos` | [S,T,n,n] | 读入前**整流**间余弦（两模型都有） |
| stream_state | `write_stream_cos` | [S,T,n,n] | 写回向量 w_s 间余弦（两模型都有） |
| stream_state | `postwrite_stream_cos` | [S,T,n,n] | 写回后残差流间余弦（两模型都有） |
| stream_state | `same_group_stream_cos` | [S,T,Q,n,n] | 同组内、各流的通道切片间余弦（**group 专有**） |
| lora | `delta_stream_cos` | [S,T,n,n] | 各流 LoRA 更新 δ_s 间余弦（group 专有） |
| lora | `lora_main_ratio` | [S,T,n] | ‖LoRA写‖/‖主写‖（group 专有） |
| lora | `lora_perp_ratio` | [S,T,n] | LoRA 更新中正交于主分支输出的比例 = \|sinθ\|（group 专有） |

> 说明：`w_s = β_s·h (+ λ·LoRA_s)`；mHC 只有主写 `β_s·h`。余弦矩阵对角恒为 1，分析时取 off-diagonal 均值。

## 使用与聚合注意
- **保存的是全量 4×4/token 级原始值，未做任何层内平均**；`stream_analysis_summary.md` 里的标量是「off-diag + 对 token/site 求均值」的**加工结果**，不要与原始张量混淆。
- **前向量完全可复现**（同协议重跑逐位一致）；**梯度类**因 SDPA 反向 atomicAdd 是**非确定性**的，逐点有 ~1e-2 抖动，但聚合均值稳定。
- `write_stream_cos` 在 β_s≈0（哑流）处会退化（零向量余弦≈0）；比较时可用 `β_s≥1e-3` 掩码（见 summary）。
